# cardiac-channelopathy
Il nostro script di analisi sfrutta le potenzialità di Python e delle sue librerie specializzate per la bioinformatica e le librerie BioPython per elaborare informazioni genetiche, valutare il potenziale impatto patogenetico delle varianti e visualizzare i risultati in modo comprensibile.
Il sistema è stato sviluppato concentrandosi su quattro geni principali coinvolti nelle canalopatie cardiache: SCN5A (canale del sodio cardiaco), KCNQ1 e KCNH2 (canali del potassio) e RYR2 (recettore della rianodina). Tuttavia, la struttura modulare dello script permette facilmente l'estensione ad altri geni di interesse.

Obiettivi
•	Identificare e caratterizzare varianti genetiche nei geni dei canali ionici cardiaci
•	Analizzare la conservazione evolutiva delle regioni contenenti varianti
•	Predire l'impatto funzionale delle varianti mediante algoritmi di scoring
•	Identificare motivi proteici conservati potenzialmente rilevanti per la funzione dei canali
•	Visualizzare i risultati mediante grafici informativi
